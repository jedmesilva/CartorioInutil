Carimbo parametrizável

Edite os campos ou passe ?data=10/10/2026&protocolo=1 na URL.

Código e parâmetros 
carimbo({ data, protocolo, cor, fundo })
// data: "10/10/2026" ou "2026-10-10" (padrão: hoje)
// protocolo: "1" vira "000001"
// cor: "#0f4c2d"   fundo: "transparent" tira o papel
// fontes: Playfair Display e Courier Prime
